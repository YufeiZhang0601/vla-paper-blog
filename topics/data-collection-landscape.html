Data Collection Landscape

数据采集全景：国内外所有在做具身数据采集的玩家，到底各自在采什么

这一篇是对UMI 数据采集专栏的外围补全。原来那篇把重心放在 UMI 家族本身， 但真正要理解今天的具身数据市场，还得把国外学术、国外产业界、国内整机厂和国内设备厂全部拉进同一张图。 这篇文章就是这张图的第一版：不止 UMI 原型机，还有像简智机器人的 Gen DAS、戴盟的 Sparky 外骨骼方案、 千寻智能 20 万小时级别的数据、Physical Intelligence 训 π0 用的 10,000+ 小时数据、Figure 的 Project Go-Big， 以及像帕西尼 Super EID 工厂这种年产近 2 亿条的数据产线。

核心对象：UMI 家族 / ALOHA 家族 / DROID / Open X / π0 / AgiBot World / Daimon / Gen DAS / Noematrix / 千寻 / 银河通用 / 灵初 / Fourier / RoboMIND / 白虎-VTouch / PaXini 核心问题：在"数据即基础设施"的阶段，谁在定义采集标准，谁在做规模化生产

先给一个总判断

去年我还觉得数据采集是工程问题，今年再看，它越来越像产业基础设施。能不能训出一个好模型， 很多时候已经不由谁拿到更大的 GPU 决定，而由谁拥有采集标准、谁拥有年产级数据产线、谁拥有跨本体的动作语言决定。

一句话记忆： 现在全世界做具身数据采集的玩家，本质上都在回答同一个问题—— 如何把人类操作、机器人控制和真实世界场景，压成一份模型真正学得动的数据，并且把这件事规模化、标准化、可复用。

按技术路线，整个生态可以分成五条路

这五条路线几乎可以覆盖所有在做具身数采的玩家。一家公司往往同时走其中 2–3 条。

路线一：便携手持夹爪 / 腕戴式（UMI 系）

代表：`UMI`、`Fast-UMI`、`Dobb·E / The Stick`、`穹彻 RoboPocket`、`自变量` 手持方案。优势是"无需机器人"就能采，边际成本极低。

路线二：外骨骼 / 数据手套（人手映射）

代表：`DexUMI`、`AirExo`、`戴盟 Sparky 外骨骼`、`简智 Gen DAS Dex`、`灵初 Psi-SynEngine`、`灵心巧手 UMI-Dex`、`BeingBeyond U1`、`Manus / HaptX / Dexmo`。核心是把人手自由度和触觉高保真投射给机器人。

路线三：主从遥操作（Leader-Follower / VR / 动捕）

代表：`ALOHA / Mobile ALOHA`、`GELLO`、`SO-100 / SO-101`、`U-Arm（SJTU）`、`松灵 Cobot Magic`、`OpenWBT`、`OpenTeach`、`Tesla 动捕服`、`HumanPlus / H2O`。是目前采真机原生数据最主流的方式。

路线四：无本体 / 头戴 / 背包式数采（Egocentric + UMI 一体化）

代表：`觅蜂 MEgo 系列（Gripper + View + Engine）`、`鹿明 FastUMI Pro / Ego / Go`、`Ego4D / Ego-Exo4D`、`Meta Project Aria`、`Figure Project Go-Big`、`Skild AI`。把互联网规模人类视频 + 第一人称+夹爪融合，做成"随走随采"的消费级数据产线。

路线五：仿真合成 + 真机微调

代表：`NVIDIA Isaac GR00T / GR00T-Mimic`、`RoboTwin 2.0`、`银河通用 星坊金字塔`、`逐际 DreamActor`。专门解决"人类采不出来、机器人采不起"的长尾分布。

国外阵营（一）：学术 / 开源

UMI 家族（Stanford Shuran Song 组的体系）

这一条我在UMI 数据采集专栏里已经讲透。这里只强调一点：UMI、Fast-UMI、DexUMI、UMI-on-Legs、HoMMI、HuMI、exUMI、Touch-in-the-Wild、ManiWAV、MV-UMI 合起来，已经是目前唯一一套公开、可复现、可规模化的便携数据接口家族，事实上的行业标准。

ALOHA 家族（Tony Zhao / Chelsea Finn 组）

ALOHA / Mobile ALOHA

双臂主从遥操作 + 移动底盘，14 DoF，商业版 $20k–$32k。是**主从数据采集最流行的范式**，论文里反复验证"50 条演示 + 静态 ALOHA 数据 co-training 就能把成功率拉高 90%"。

HumanPlus (CoRL 2024 Best Paper Finalist)

单目 RGB 实时 shadowing 一台 33 DoF humanoid，结合 40 小时人类动捕做 sim pretrain。关键意义是把"穿越身体结构差距"这件事做到了只靠一台 RGB 相机。

OmniH2O / H2O（CMU）

全身遥操作框架，可 zero-shot 走、跳、踢、打拳，是目前动态 whole-body 数据采集的代表。

低成本 DIY 阵营：真正让学生也能采的那一层

GELLO（UC Berkeley）

$300 的 3D 打印"小机械臂当摇杆"，用 Dynamixel 舵机做 50–200Hz 关节映射，已适配 Franka / UR5 / xArm。

U-Arm（上海交通大学 MINT Lab）

GELLO 的国产低成本版，BOM 仅 $50.5（6-DoF）/ $56.8（7-DoF）。3 种主臂构型适配 xArm6 / Dobot CR5 / ARX R5 等市面 95% 机械臂。工程上用改装舵机（去齿轮保编码器）+ 冗余自由度标定滤波，实验显示比 Joycon 采集效率高 39%。（arXiv 2509.02437 / GitHub / Hugging Face Paper / 量子位报道）

AirExo / AirExo-2

每只手臂约 $300 的纯机械外骨骼，可在**没有机器人的野外**采数据再映射到机器人。"3 分钟真机 + 大量野外" ≈ "20+ 分钟真机 teleop"。

SO-ARM100 / SO-101（LeRobot 生态）

Hugging Face LeRobot 主推的开源主从双臂，入门 <$500。目前国内大量实验室和个人走的就是这条路。

Dobb·E / The Stick（NYU + Meta）

$25 延长杆 + iPhone 组装的"捡拾杆"，在 22 个纽约家庭采集了 13 小时、150 万帧、216 个环境的 **HoNY 数据集**；109 个家庭任务 81% 成功率。它是"零成本家庭采集"的教科书样本。

RoboTurk / Open Teach / AnyTeleop

三条路线：手机当 6DoF 控制器的众包（Stanford）、Meta Quest 3 MR 透视遥操作、纯视觉统一多臂多手多仿真。覆盖 38+ 灵巧任务。

国内阵营（一）：便携 / 可穿戴设备厂商

这是我最想在这篇全景里讲清楚的一层。国内最有意思的，其实是一批专门做"数据采集设备"的公司——他们不一定做整机，但他们在定义整个行业怎么采。

戴盟机器人（Daimon Robotics）— Sparky 1 + DM-Tac

Sparky 1 人形配套**外骨骼遥操作方案**：图像头盔 + 6/7 DoF 外骨骼双臂 + 五指数据手套，动作映射误差 <5%。触觉侧 DM-Tac W / DM-Tac F 视觉触觉传感器：W 系列每平方厘米 >4 万感测单元、120Hz、300 万次寿命；F 系列用于指尖。
注：关于"Daimon-Infinity 一万小时数据集"这个说法，公开资料里我没找到官方发布页，目前戴盟对外主打的是 Sparky + DM-Tac + 外骨骼这套方案。

简智机器人 — Gen DAS Dex（即 Gen DAS Fingers）

非夕孵化。CoMiner 伴随式数采套件：模块化关节、兼容多本体、遥操作 + 野外两种模式、单机单日产能 >1000 条。RoboPocket 口袋机采：用手机 RGB + LiDAR 替代专业采集设备，把"定点采集"升级成"随时随地"，首月签数百套。配套 Noematrix Toolchain 做采集—管理—训练—部署全流程。

官方产品名实际上是 Gen DAS Dex，不是单独的"Fingers"。它是一套外骨骼手套 + Ego 头显的协同采集套件：23 DoF 覆盖整只人手、210g、0.02° 关节精度、指尖毫米级、1ms 同步、续航 3h、支持流式上传。这是国内目前最对标 DexUMI 的商业化方案。

"戴盟机器人 Daimon-Infinity 一万小时数据集"

公开资料中我没有找到以"Daimon-Infinity"为名的正式发布页面。戴盟目前公开主打的是 Sparky 1 外骨骼采集方案（图像头盔 + 外骨骼双臂 + 五指数据手套）+ DM-Tac W/F 视触觉传感器。如果这是内部最新项目，建议直接问戴盟或留意其 2026 年的产品更新。

一个判断： 国内这批"数据采集设备厂"（戴盟、简智、穹彻、帕西尼、灵初）是这两年新出现的一层生态位。他们的共同思路是 "我不做整机，我做机器人吃的饲料"——这在 VLA foundation model 时代可能是非常重要的一层。

五个关键趋势

1. "去机器人化采集"成为共识

UMI、Dobb·E、AirExo、Figure Go-Big、穹彻 RoboPocket、简智 Gen DAS、鹿明 FastUMI 全家桶、觅蜂 MEgo 无本体数采、灵心巧手 UMI-Dex都在绕开昂贵本体，把人类直接变成数据源。"无本体数采"已经从学术术语变成了消费级产品名。

2. 数据规模正从"千小时"→"万小时"→"百万小时" → "千万小时"跃迁

π0 10,000h、灵初 Psi-SynEngine 10 万 h、鹿明 FastUMI 已交付 100 万条、千寻目标 100 万 h、觅蜂 MEgo 2026 目标 1000 万小时 / 2030 百亿小时、帕西尼年产 2 亿条。数据曲线的斜率，比过去两年的任何模型改进都陡。

3. 触觉正在成为新战场

戴盟 DM-Tac、帕西尼 ITPU、DexUMI、exUMI、国地白虎-VTouch 都在抢"触觉数据标准"的定义权。纯视觉的时代正在过去。

4. 合成数据不是备选，是必选

银河通用、NVIDIA GR00T、RoboTwin、逐际都在做"仿真打底 + 真机微调"。真机数据贵、长尾稀、失败不可采——这三件事决定了仿真必须到场。

5. 开源工具链决定生态控制权

LeRobot、OpenWBT、X-Humanoid Toolchain、Fourier ActionNet、Noematrix Toolchain、灵心巧手 UMI-Dex（业内首个开源灵巧采集）、SJTU U-Arm（$50 BOM 的 GELLO 国产版）——这些工具链背后都是同一个问题：谁定义采集标准，谁就定义下一代 foundation model 的数据语言。

如果只记住三句话

  1. 今天的具身数据市场，不再只是 UMI vs ALOHA vs DROID 这种学术对比，而是"设备厂 / 整机厂 / 国家队 / 工厂数据源"四层并存。
  2. 国内最值得单独看的，是简智 Gen DAS、戴盟 Sparky、穹彻 CoMiner、帕西尼 Super EID、鹿明 FastUMI 全家桶、觅蜂 MEgo、灵心巧手 UMI-Dex、BeingBeyond U1这一批"专做饲料"的公司，以及智元 AgiBot World、千寻、灵初 Psi-SynEngine 这些已经跑到万小时级别的"自建数据"公司。
  3. UMI 仍然是学术侧最值得深挖的节点，但下一轮竞争的赢家，很可能来自"谁有能力把采集做成年产数千万到亿条的工业产品线"。
