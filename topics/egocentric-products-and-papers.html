Egocentric Products & Papers

Ego 全景篇：市面上所有"第一人称"产品 + 数据集 + 论文，一次性梳理清楚

如果说 UMI 解决的是"手怎么采"，那么 ego 这条线解决的是"眼睛和头怎么采"。 过去两年发生的事是：以 Meta Project Aria 为起点， 第一人称（egocentric）智能眼镜 + 多模态传感 + 大规模真人日常数据 已经形成了一条独立的供应链，国内（觅蜂、简智、鹿明）也在 2026 年集体跟进。 这一篇把硬件产品、公开数据集、ego-vision 基础模型、ego→robot 论文四类全部拉到一张图里。

核心硬件：Aria Gen 1 / Aria Gen 2 / Quest 3 / Vision Pro / Ray-Ban Meta / MEgo View / Gen DAS Ego / FastUMI Ego 核心数据集：Ego4D / Ego-Exo4D / Nymeria / HOT3D / AEA / Aria Gen 2 Pilot / Ego-1K 核心论文：EgoMimic / EgoZero / EgoHumanoid / EgoMI / ActiveGlasses / Open-TeleVision / VisionProTeleop / GenEgoData / EgoVLP / LaViLa
这一篇放在哪个位置？ 如果你已经看过 数采专栏（UMI 学术线） 和 数采全景篇（产业线）， 那么这一篇就是它们的第三块拼图：把"头戴 / 眼镜类 ego 设备"和"第一人称数据"专门拎出来讲，因为这一类的硬件形态、数据采集流程、可学习信号和前两条线都不一样。

0. 一句话定义：什么算"ego"，不算"ego"

这篇里"ego"特指 egocentric capture：传感器戴在人的头上、脸前或眼前，记录"佩戴者第一人称看到的世界 + 自身运动 + 注视点"，再把这些数据喂给机器人 / VLA / world model。

算 ego ✅

智能眼镜（Aria）、VR 头显（Quest 3 / Vision Pro）、头戴相机（GoPro head mount）、消费级 AR 眼镜（Ray-Ban Meta）、国内的 MEgo View / Gen DAS Ego / FastUMI Ego。

不算 ego ❌

UMI 手柄（wrist-view 第一夹爪视角而非第一人视角）、ALOHA 机器人本体相机、桌面摄像头、外骨骼掌心相机。

边界情况 ⚠️

胸戴系统（DexCap）、肩戴 GoPro：通常归类为"body-worn"而非严格的 ego，但跟 ego 数据共享大量学习信号，所以本篇也会带一笔。

为什么要专门拉一条 ego 线： UMI 类（手腕 / 夹爪视角）只能告诉机器人手在干嘛； ego 类同时告诉它眼睛在看哪、头怎么转、注意力在哪。 对未来的 humanoid / mobile manipulation / 多步任务来说，这两路数据是互补而不是替代。

1. 国外 ego 硬件：Meta 一家独大，Apple / Snap / 创业公司补位

1.1 Meta Project Aria Gen 1（2020）

Meta Reality Labs Research 在 2020 年发布的研究专用智能眼镜，不卖给消费者，只通过 Aria Research Kit 发给学术合作机构。它定义了"egocentric multimodal capture"这条赛道的事实标准：RGB + 双 SLAM 灰度 + 眼动 + 双 IMU + 麦克风。今天几乎所有 ego 数据集（Ego4D、Ego-Exo4D、Nymeria、HOT3D、AEA）都是用 Aria 采的。

关键传感器

1× RGB（1408×1408）+ 2× 单色 SLAM（640×480）+ 2× 眼动 + 2× IMU + 7 通道麦克风 + 磁力计 + 气压计。

核心能力

Sub-ms 多设备时间同步、机器感知 SDK（SLAM、3D 点云、6DoF 位姿、眼动 gaze），数据通过官方 projectaria_tools 解析。

资源入口

官网 / SDK / 公开数据集索引

1.2 Meta Project Aria Gen 2（2025-02 发布）

2025 年 2 月发布的第二代研究眼镜，重点不是炫技，而是把"人形机器人需要的传感"打满：增加了鼻托 PPG 心率、骨传导麦克风用于区分佩戴者声音、4 路 CV 摄像头扩展到 30 Hz、加入定制 Meta SoC 做端上 SLAM / 手追 / 眼动 / 语音。整机 ~75g，可折叠，支持 6–8h 录制和实时流。

新增传感

PPG（脉搏 / 心率）、contact mic（区分佩戴者 vs 周围声音）、新一代 8MP RGB（最高 2560×1920）、改进的 dual fisheye 立体 + 4× CV 灰度 + 眼动 + 双 800 Hz IMU + 磁力计 + 气压计 + GPS。

端上算力

Meta 自研 silicon，支持 ultra low-power 端上 SLAM / 手追 / 眼追 / 语音识别，可实时输出感知信号到下游 robot policy。

资源入口

官方 Blog / Device Paper / Tech Specs / Gen 2 Pilot Dataset

1.3 Meta Quest 3 / Quest Pro（消费级 VR 头显，但被大量学术工作征用）

Quest 3 不是为 ego 数据设计的，但它有 4 路前置 SLAM 摄像头 + Snapdragon XR2 Gen 2 + 内置手追，价格只有几千元，被 HOT3D、Ego-1K 这种数据集拿来当 Aria 的消费级孪生。Apple Vision Pro 出现以前，Quest 3 是社区里"既能 ego 采、又能 VR teleop"的最便宜方案。

1.4 Apple Vision Pro（2024-02 发售）—— 不是为采数据，但变成了 ego teleop 的事实标准

Vision Pro 自身不开放原始 SLAM / 眼动数据流，但凭立体直通 + 高精度手追 + 眼动反馈成了 humanoid teleop 的事实选择。Open-TeleVision 和 VisionProTeleop 两个项目让它一边做沉浸式遥操，一边做第一视角数据录制。

Open-TeleVision（UCSD + UCB, MLR 2025）

Project / arXiv 2407.01512 / Code。 用 Vision Pro / Quest 给两台不同 humanoid 做沉浸式立体 teleop，已用 4 个长程精细任务（罐子分类、罐子插入、折叠、卸货）验证模仿学习闭环。

VisionProTeleop（MIT Improbable AI）

GitHub。 一站式：真机 teleop + MuJoCo / Isaac Lab 仿真 + egocentric 数据集录制 + 云存储。是目前 Vision Pro 入门最快的方案。

HumanPlus（Stanford）

用 Vision Pro 第一人称视角 + 全身动捕训练 humanoid，是 Vision Pro × ego × humanoid 三者打通的早期代表。

1.5 Ray-Ban Meta 智能眼镜（消费级量产，2023+）

消费级智能眼镜，单 RGB + 立体麦 + 端上 LLM。它不是研究设备，但它代表"Aria 类硬件如何低成本量产"。Meta 已经多次表示后续 Ray-Ban Meta 会反向用 Aria 数据集训练，所以它在 ego 生态里更像"出口产品"，而不是采集端。

1.6 Microsoft HoloLens 2（HoloAssist 数据集的硬件来源）

微软早期的 AR 头显，CMU + 微软在它上面采了 HoloAssist（166h，350+ 任务，专家–新手协作 ego 数据），是 ego 任务理解 / 装配引导类工作的常用基准。

1.7 Snap Spectacles AR / Even Realities G1 等

面向 AR 应用的消费级智能眼镜，硬件指标弱于 Aria，几乎不出现在学术 ego 数据采集场景，主要意义是"未来 ego 设备会朝什么形态量产"。

1.8 DexCap（Stanford, RSS 2024）—— 严格说是 body-worn，但常被并入 ego 讨论

Project / arXiv 2403.07788。 胸戴 RGB-D + 双手 SLAM 手套，做的是portable in-the-wild dexterous data capture。视角不是头部而是胸前，但学习信号、目标场景、训练范式都和 ego 高度同构，所以社区习惯把它放在一起讨论。

2. 国内 ego 硬件：2026 年集体爆发，已经形成"头戴产品线"

2026 上半年国内具身赛道的一个明显信号是：原本只做手部 / 夹爪数据的厂商，集体补齐头戴产品。下面三家都是在 2026-Q1 / Q2 公开发布过具体产品的，可以理解为"国内 Aria 的三种打法"。

2.1 觅蜂科技 MEgo 系列（智元孵化, 2026-04）

定位

"无本体采集"产品矩阵的头戴端，行业首创全场景 + 全视角采集终端。MEgo View 已发布，目标 2026 年完成 1000 万小时数据交付。

硬件参数

超 300° 全景感知 + 腕部交互特写双视角；毫米级轨迹重建（操作轨迹还原精度 1mm）。

资源入口

网易：觅蜂发布 MEgo / 投资界报道

2.2 简智机器人 Gen DAS Ego（2026-Q1）

定位

简智已有"Gen DAS Fingers"手部数据手套，Gen DAS Ego 把同一套无感采集理念扩展到头部，对标 Aria 但偏向"全天候作业级别"。

硬件参数

6× 200W 高清摄像头 + 内置 IMU；水平 270° + 垂直 150° 超广视野；350g 轻量化无感设计；支持 24h 不间断作业；厘米级检测精度；语音交互控制。

资源入口

GenEgoData 发布报道（首推具身世界模型专用数据集）

2.3 鹿明机器人 FastUMI Ego（AWE 2026 发布）

定位

"全球首款即插即用、无需建图的第一人称数采方案"，是鹿明 FastUMI 全家桶里的头戴一员，主打"拿上眼镜就能采、不需要预建场景地图"。

硬件参数

水平 + 垂直视场角均 > 180° 超广角；左右手独立追踪；空间定位精度 3mm；整机 235g，均衡配重。

资源入口

凤凰网：FastUMI Ego 发布 / fastumi.com 项目主页

三家放在一起对比： 觅蜂 MEgo View 走的是"极广视场 + 工业级数据生产线"； 简智 Gen DAS Ego 走的是"多目高清 + 24h 工业全天候"； 鹿明 FastUMI Ego 走的是"轻量 + 即插即用 + 跟手臂数据原生互补"。 它们都不是 Aria 的复刻——而是在 Aria 已经定义好的多模态 ego 数据范式之上， 各自押注一个工业落地角度。

4. Ego-vision 基础模型：从 EgoVLP 到 LaViLa，再到机器人 policy

这一层不是采数据，而是怎么利用 ego 数据训练通用视觉 / 视觉-语言模型，是后面 ego→robot 应用的"上游"。

EgoVLP（NeurIPS 2022 Spotlight）

第一个 egocentric video-language pretraining 框架，奠定 ego 视频 + 文本对比学习路径。Ego4D Challenge 2022 OSCC 第一、NLQ 第二。论文 / Code

EgoVLPv2（ICCV 2023, EgoVis Distinguished Paper 2024）

把跨模态 fusion 直接放进 backbone，比"分别编码 + 后期融合"更轻量；在 EgoMCQ / EgoNLQ / EgoMQ / EgoTaskQA 等多个 benchmark 上 SOTA。Project / Code

LaViLa（Meta, CVPR 2023）

"用 LLM 生成自动 narration"，再回头训练 ego video–language。EGTEA 分类 +10.1%，EPIC-100 retrieval +5.9%；最先证明 ego VLP 可以随预训练数据 + 模型规模正向 scaling。Project

Ego-LLaVA / Ego-OnlyVL 类

2024–2026 出现一批"ego-tuned MLLM"：把 LLaVA / Qwen-VL 在 Ego4D + EgoSchema 上继续做 instruction tuning，目标是让多模态大模型"会读第一人称视频"。这是后面 ego→VLA 的关键能力底座。

5. Ego → Robot：用第一人称数据驱动机器人学习的关键论文

这一节是把 ego 数据真正变成机器人能力的工作。按"用什么 ego 设备 + 是否需要机器人本体数据"两个维度来组织。

5.1 EgoMimic（Georgia Tech + Meta，CoRL 2024）

关键贡献

Project Aria 第一次直接进入 manipulation pipeline。用 Aria 拍人手做日常任务，配合低成本双臂 Eve 机器人采少量 robot 数据，co-training 出统一 policy。

关键发现

+1h 人手数据 ≫ +1h 机器人数据；EgoMimic（2h robot + 1h hand）整体优于 ACT（3h robot）；新场景成功率提升 34%–228%。

资源

Project / arXiv 2410.24221 / Code / Eve 平台

5.2 EgoZero（NYU + Meta，arXiv 2025-05）

关键贡献

"Robot Learning from Smart Glasses"。完全只用 Aria 智能眼镜，0 条机器人训练数据，从野外人类示范里抽取可执行动作，部署在 Franka Panda 上。

关键发现

每个任务只用 20 分钟人类示范；7 个任务（开烤箱、抓面包、扫地、擦黑板、分类水果、叠毛巾、插书）平均成功率 70%；零样本迁移到不同物体、相机（iPhone vs Aria）、机器人工作空间。

资源

Project / arXiv 2505.20290 / Code

5.3 EgoHumanoid（arXiv 2602.10106, 2026-02）

关键贡献

第一篇把 ego 人类示范用于 humanoid loco-manipulation 的工作。提出 view alignment + action alignment 两条 pipeline 弥合 ego–robot embodiment gap。

关键发现

在真实环境 loco-manipulation 任务上比"纯机器人数据"基线 提升 51%，第一次实现"少量机器人 + 大量 ego 人类示范"在 humanoid 上的协同。

资源

arXiv 2602.10106

5.4 EgoMI（arXiv 2511.00153, 2025-11）

关键贡献

"Egocentric Manipulation Interface"：同时记录 end-effector 轨迹 + 主动 head 视角轨迹，用 memory-augmented policy 解决 ego 视角下的"头一直在动"问题。

关键发现

把"手眼协调"作为可学习信号显式建模，让半 humanoid 机器人也能像人一样"边看边动"，而不是死盯一个固定相机。

资源

arXiv 2511.00153

5.5 ActiveGlasses（arXiv 2604.08534, 2026-04）

关键贡献

用智能眼镜立体相机采集 ego 数据，提取物体 3D 轨迹 + 手追，用 object-centric point-cloud policy 联合预测操作动作 + 头部运动。

关键发现

实现跨机器人平台零样本迁移：在一种 embodiment 上 ego 数据训出来的 policy，可直接部署到另一种结构的机器人上。

资源

arXiv 2604.08534

5.6 Open-TeleVision & VisionProTeleop（Vision Pro 沉浸式 ego 遥操）

这两条已经在第 1.4 节列过参数。在论文索引层面要记住的一点是：它们把 Vision Pro 从消费品变成了 ego × humanoid 的标准 teleop 控制器，是 ego→robot 应用最容易复现的入门路径。

5.7 GenEgoData × 简智 Gen DAS Ego（国内）

对应国内"Ego 数据 → 具身世界模型"那条线。Gen DAS Ego 头戴 + Gen DAS Fingers 手套同步采集，目标不是直接学 manipulation policy，而是先训第一人称 world model，再做下游 planning / VLA。发布报道

5.8 其他值得跟进的 ego × robot 工作

  • HumanPlus / OmniH2O（Stanford）：ego 视频 + 全身 retargeting 训 humanoid，是"ego × whole-body teleop"早期代表。
  • Vid2Robot / R3M / VC-1：把 ego 数据当视觉表征预训练语料，再迁移到 robot policy。属于"ego 数据更上游"的用法。
  • EgoSchema / EgoQA + VLA：把 ego 长视频问答能力嫁接到 VLA，让模型"看懂家务流程"再去做。
  • Being-H0.5 / UniCraftor（详见 数采专栏）：虽然主线是手部数据，但它的 35,000h UniHand-2.0 数据集中相当一部分是 ego 第一人称视角，可视为"ego × manipulation"的国内代表。

6. 五个值得记住的趋势

  1. Aria Gen 2 把 ego 设备从"研究原型"推到"机器人感知前端"。端上 SLAM / 手追 / 眼追全部内置，这意味着以后 ego policy 可以实时用眼镜的输出，而不是只用录好的离线数据。
  2. "消费品复用"成为 ego 落地的最快路径。Quest 3 和 Vision Pro 都不是为 ego 数据设计，但 HOT3D / Open-TeleVision / VisionProTeleop 已经把它们变成事实工具，国内的 MEgo / Gen DAS Ego / FastUMI Ego 也在沿着"消费眼镜形态 + 工业级数据生产"的路子走。
  3. 多视角 (ego + exo) 成为新基线。Ego-Exo4D 把"同步第一人称 + 第三人称"做成默认动作，后续的 ActiveGlasses、EgoMI、EgoHumanoid 都默认要解决"头会动 + 视角会跳"。单视角 ego 数据训出来的 policy 已经被认为不够用。
  4. Ego 数据在 imitation learning 里和机器人数据"等量齐观"。EgoMimic 给出了"1h 人手 ≥ 1h 机器人"，EgoZero 直接 0 条机器人数据 70% 成功率。这条结论会重新定义"具身数据采集"的成本结构——以后多采人，少采机。
  5. 国内厂商开始押注"ego = world model 训练数据"。觅蜂 MEgo / 简智 GenEgoData 都不打算只做 manipulation，而是把 ego 数据视作具身 world model 的预训练语料。这跟 Sora / Genie 那条路融合，是 2026 下半年最值得跟踪的方向。
