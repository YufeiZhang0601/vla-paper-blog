RT-2：VLA 范式是怎么被立起来的

RT-2 最重要的贡献不是某个单点指标，而是它证明了一个强命题：机器人动作也可以被当成“语言”来建模。

关键词：action tokenization / co-fine-tuning / web knowledge transfer

它到底解决了什么

在 RT-2 之前，大家知道视觉语言模型很强，也知道机器人策略能从示范里学动作，但两者之间并没有一个足够自然的统一接口。

RT-2 的回答很大胆：既然语言模型本来就擅长生成 token，那就把机器人动作也编码成 token，让模型把动作当成另一种“文本”生成。

技术实现抓手

  1. 把连续机器人动作离散化为多个 action tokens。
  2. 把图像、语言指令、动作 token 放进同一序列建模框架。
  3. 在机器人轨迹数据和互联网视觉语言任务上共同微调，而不是只用机器人数据。
关键直觉：如果动作和文本进入同一 token 空间，VLM 原有的语义知识就有机会迁移到机器人控制里。

为什么它影响这么大

因为 RT-2 让 VLA 从“机器人策略学习的小分支”变成了“大模型具身化”的主线问题。后来的 `OpenVLA`、`Xiaomi-Robotics-0` 都在不同程度上继承这个统一建模视角。

局限也很明显

动作离散化会带来精度损失；token 自回归输出在高频控制场景下也可能太慢。这正是后来大家开始研究连续动作头、扩散动作生成和低延时异步执行的原因。
