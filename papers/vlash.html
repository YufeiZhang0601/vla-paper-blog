Asynchronous Inference

VLASH：异步推理真正的问题不是“边执行边算”，而是“算的时候身体已经变了”

VLASH 是我很推荐新手认真读的一篇实时论文，因为它特别清楚地指出：异步推理的根因不是 stall 本身，而是 prediction interval 和 execution interval 错位。

先看错误发生在哪里

在 naive async 中，模型在时刻 t 用状态 s_t 预测动作，但等这段动作真正开始执行时，机器人已经在 s_{t+\Delta} 了。

所以问题不是“动作错”，而是“动作打在错误状态上”。

VLASH 的关键想法

既然执行开始前，机器人还会把上一段剩余动作执行完，那这些动作其实是已知的。于是我们可以利用这些已知动作把机器人状态向前滚动，得到动作真正执行时的 future state。

为什么只在测试时喂 future state 不够

作者发现现有 VLA 往往太依赖视觉输入，未必真的会使用 state token。所以 VLASH 在训练时做 temporal-offset augmentation，把同一图像对应到不同 offset state 与 action，逼模型学会关注 state。

我为什么觉得它很高级

它没有靠新增复杂模块硬修异步问题，而是从“条件变量应该是什么”这个角度重写了任务定义。对系统代价小，但抓到了核心矛盾。
